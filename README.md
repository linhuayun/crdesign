# crdesign

## 文档定位

| 维度                | 定位                              |
| ----------------- | ------------------------------- |
| **文档性质**          | 承上启下的过渡方案                       |
| **上游**            | 决策层已拍板"要做"                      |
| **下游**            | 指导各产品团队产出PRD、认领任务               |
| **核心读者**          | 部门负责人（向上汇报 + 向下分解任务）            |
| **内容边界**          | 业务能力定义（系统输入）+ 系统/子系统划分与职责（分工依据） |
| **不涉及**           | 详细产品功能清单、交互设计、数据库字段设计           |
| **第一章**           | 面向产品团队和客户的首个统一文档，需要说明为什么做，哪些是重点 |
| **关键技术**          | 仅识别描述，放附录                       |
| **规则/度量/评测的详细实现** | 放附录，第三章只保留业务视角                  |
